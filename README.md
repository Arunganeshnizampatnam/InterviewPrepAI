# InterviewPrepAI

AI-Powered Interview Preparation Platform

## Features

- Aptitude Questions
- Technical Questions
- HR Interview Questions
- Resume Analyzer

## Technologies Used

- Python
- Flask
- HTML
- CSS

## How to Run

1. Install Flask

   pip install flask

2. Run the application

   python app.py

3. Open

   http://127.0.0.1:5000
